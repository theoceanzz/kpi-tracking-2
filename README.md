# kpi-tracking-2
Hệ thống KeyLearn là nền tảng SaaS multi-tenant cho phép nhiều trường học đăng ký và vận hành độc lập. Mỗi trường tự quản lý cơ cấu tổ chức, khoa/phòng ban, giáo viên, học sinh và chương trình đào tạo riêng. Hệ thống cung cấp luồng duyệt kế hoạch đào tạo từ giáo viên lên trưởng khoa và báo cáo tổng hợp để ban giám hiệu đánh giá hiệu quả giảng dạy.
